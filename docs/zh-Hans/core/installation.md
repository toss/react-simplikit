# 安装

你可以使用自己喜欢的包管理器，从 [npm](https://npmjs.com/package/react-simplikit) 安装 `react-simplikit`。

::: code-group

```sh [npm]
npm install react-simplikit
```

```sh [pnpm]
pnpm add react-simplikit
```

```sh [yarn]
yarn add react-simplikit
```

```sh [bun]
bun add react-simplikit
```

:::
